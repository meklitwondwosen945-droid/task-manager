# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-11

### Added
- Initial release of TaskFlow
- Task creation with title, description, priority, and due date
- Task editing functionality
- Task deletion with confirmation
- Task completion toggle
- Search functionality for tasks
- Filter tasks by status (All, Active, Completed)
- Sort tasks by date, priority, or title
- Statistics dashboard with progress tracking
- Sidebar navigation
- Settings modal with export functionality
- Responsive design for mobile and desktop
- Backend API with Express
- In-memory storage support
- MongoDB integration support
- Beautiful modern UI with Tailwind CSS
- Smooth animations and transitions
- Due date tracking with overdue indicators
- Priority levels with visual indicators
- Comprehensive documentation

### Technical
- React 18 with TypeScript
- Vite for fast development
- Zustand for state management
- Express backend
- REST API
- CORS enabled
- Error handling
- Loading states
